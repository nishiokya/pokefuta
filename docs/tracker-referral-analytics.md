# 図鑑から写真館への流入県

図鑑が渡す `from=data&pref=<県slug>` を写真館で受け取り、`referral_prefecture` として送る。投稿・閲覧対象の `prefecture` とは別の軸であり、値を上書きしない。

- 既存の47県slugのみ許可。`from=data` がないprefは流入情報として採用しない。
- 同じタブの直近の図鑑流入をsessionStorageに保存し、画面遷移・再読み込み・同じタブの認証復帰で引き継ぐ。新しい図鑑流入に県がなければ古い県を消す。
- 計測対象のページ表示・イベントから30分無操作で失効する。GA4のセッションIDとは独立した補助的な帰属ルールである。新しいドキュメントで図鑑パラメータ付きURLを開いた場合は新たな流入として扱う。
- storageが利用できない場合は同じドキュメント内のみ保持する。別タブ・別端末への引き継ぎは保証しない。
- `page_view`、実際の図鑑着地の `p_data_referral`、共通trackEventを使うイベント（両投稿フロー・訪問登録など）に付ける。保持中は `source_app=tracker` も付ける。内部遷移だけで `p_data_referral` を増やさない。
- 本番ホスト制限・URLの機密情報除去・クロスドメインリンカー・標準page_view一回の契約を維持する。

## 本番反映前

GA4プロパティ507799028にイベントスコープのカスタムディメンションを登録する。

| 表示名 | イベントパラメータ | 意味 |
| --- | --- | --- |
| 図鑑の流入元都道府県 | referral_prefecture | 図鑑で最後に着地リンクをクリックした県ページのslug |

登録前に届いたパラメータは探索へ遡及適用されないため、登録確認前に本番反映しない。
探索では `p_data_referral` → `p_submission_start` → `p_photo_upload_complete` をこの軸で分解する。訪問登録は `p_visit_register` を別に見る。URLに残るprefや対象県のprefectureを代用しない。

## 検証

`npm run test:analytics` は47県検証、内部遷移・認証復帰、流入の置き換え、期限切れ、storage拒否、両投稿系統と訪問登録の送信を検証する。
