# 共通ブランドアイコン

2026-10-11 採用: 「立てたふた＋白いカメラ」。茶色の格子入りマンホールを背面に、白いカメラを手前に重ねる。

内側は茶色（`#936B53`）、格子線は太い白（`#FFFDF4`）、外枠は濃い茶色（`#663F35`）。白いカメラは初稿から約10%縮小。全体を枠いっぱいに配置して下の余白を減らす。

カメラは上寄せにして、ふたの白い下半分の露出を減らす。

- `public/brand-icon.svg` をヘッダーとfaviconで共用する。
- 図鑑の `apps/web/assets/brand-icon.svg` と同一のSVGを使う。変更時は両サイトを更新する。
- faviconは16/32/48pxのICO、48/96pxのPNG、SVG。ホーム画面用は180px、manifest用は余白をつけた192/512px。
- OGP・地図マーカーは別用途のため、この変更には含めない。
- このマークは非公式サービスの表示用。デザイン選定は法的な安全性の確認を意味しない。
